# Kommunale informasjonspunkter, oktober 2026

Where residents should go for information and help when power, mobile and internet are down (DSB's *Veileder om kommunale informasjonspunkter ved bortfall av elektronisk kommunikasjon*). Kommunene call them informasjonspunkt, infopunkt, beredskapspunkt, krisepunkt, oppmøtested or møteplass. Public shelters (tilfluktsrom) are not included.

**Not checked by a person.** Collected 2026-10-27 by AI agents reading each kommune's own website, so every entry needs a human check (LAUNCH.md §9) before the app shows it. Data: [JSON](informasjonspunkter-2026-10-27.json), [CSV, one row per point](informasjonspunkter-2026-10-27.csv).

## Summary

All 357 kommuner (Kartverket's list) have an entry. There is no national dataset.

- **found**, named points: 237 kommuner, 829 points (508 with a street address)
- **mentioned_no_list**, says it has or plans points but names none: 22
- **not_found**, nothing found: 98

## Caveats

- Most pages were published during Egenberedskapsuka (26 Oct–1 Nov 2026), and many kommuner are still setting points up. A re-check in a few weeks will turn some `not_found` into `found`.
- Web search ran out partway, so many `not_found` entries rest on reading the kommune's beredskap pages and sitemap directly. Some sites only render in a browser, and some lists are in PDFs or images that weren't read. The `comment` says what was checked.
- Not every list is the same thing: some are staffed information points, some are notice boards or shops where posters go up, some are acute-help meeting points, and a few are still only planned (Bergen, Lindesnes, Oppdal, Steigen). Read the `comment` and `notes`.
- Name clashes to watch: Herøy (1515 Møre og Romsdal, heroy.kommune.no; 1818 Nordland, heroy-no.kommune.no), Våler (3114 Østfold, valer.kommune.no; 3419 Innlandet, vaaler-he.kommune.no), Bø (1867, boe.kommune.no).
- Tromsø's postal place names were inferred from postal codes, not read from the page.
- Spot check of 4 random `found` entries against their pages: names and addresses matched in all 4 (Kongsberg, Beiarn, Åmli, Nord-Odal, where one address came from a search result and is flagged).
